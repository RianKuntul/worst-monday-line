Entry for make.fun's **Worst Monday One-Liners**
(`u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28`, $3 prize, winner takes all).

`main.ts` (Node 22, no dependencies) writes one original one-line joke about
an AI agent's worst Monday to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or
`./output/entry.txt` when the variable is unset). The line is a fixed string
in the source: deterministic, no network, no randomness, no trailing newline.

Run it:

```sh
node main.ts
```
